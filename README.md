# 📊 Global Superstore Data Analysis Dashboard

An interactive **Power BI Dashboard** designed to analyze Global Superstore sales data and transform raw business data into meaningful insights. This project provides detailed visual analysis of sales, profit, customer behavior, regional performance, and category-wise trends to support data-driven decision-making.

# 🚀 Project Overview

This dashboard helps businesses understand:

- Regional sales performance
- Profit distribution across categories
- Customer segmentation insights
- Country-wise sales analysis
- Category and sub-category contribution
- Business growth patterns and trends

The dashboard is built using **Power BI** with interactive visualizations and slicers for dynamic analysis.
